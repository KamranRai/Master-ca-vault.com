LEGAL Accessibility

Accessibility Statement

We want everyone who administers construction contracts to be able to use this website.

How this site is built

  • Semantic HTML with one H1 per page and ordered headings.
  • Every interactive element is reachable by keyboard with a visible focus state.
  • Motion is reduced or removed when your device asks for reduced motion.
  • Images of the product have text alternatives.
  • Text and controls are designed to meet contrast requirements.

Report a barrier

If something on this site does not work for you, please tell us so we can fix it.
